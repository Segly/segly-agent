# Security

Please report suspected vulnerabilities privately through GitHub private vulnerability reporting for the `Segly/segly-agent` repository. If that channel is unavailable, email security details to support@segly.io and include “Security” in the subject.

Do not open a public issue containing API keys, OAuth tokens, recovery secrets, webhook secrets, signed URLs, payment data, private filenames, image content, or layer names.

Supported releases are the latest non-deprecated npm version and the matching immutable `v*` tag. Compromised credentials should be revoked immediately from Segly account settings.
